# 반도체설비보전 마스터

반도체설비보전기능사(구 **반도체장비유지보수기능사**, 2024년 명칭 변경) **필기 개념** 학습도구.
단일 HTML 하나(`index.html`)로 끝나고, 더블클릭으로도 열립니다.

**배포:** https://hongyul67-cpu.github.io/semicon-maintenance-master/

## 구성

| 단계 | 내용 |
|---|---|
| 🎓 수업 슬라이드 | **9장**. 교재 도해 + 요점 + **발문** + 즉석 퀴즈를 3단계로 하나씩 공개. 교사가 앞에서 진행 |
| 📖 배우기 | **16단원 69쪽**. 정답이 다 적혀 있는 설명 카드 |
| 🎮 게임 | ① 8대 공정 라인 세우기 ② 설비 이상 진단실(18증상) ③ 설비 계산소(생성기 12종) |
| 🎯 빠른 점검 | 20문항 |
| 🏁 실전 모의고사 | **60문항 · 60분 · 60점 합격** |
| 📜 기출문제 | **2014년 60 · 2015년 60 · 실전모의 50 = 170문항** (원본 그대로, 그림 10장 포함) |
| 🔒 교재 문제은행 | 암호를 넣어야 열리며, 풀리면 출제에 함께 들어감 |

문제은행: 자작 **113문항** + 교재 전사 **60문항**(잠금) = 173문항, 기출 별도 170문항.

### 수업 슬라이드 조작
좌우 스와이프 · ←/→ · Space · **PageUp/PageDown(프레젠터 리모컨)** · F 전체화면 · Esc
하단 버튼: 「이전 / 발문 열기→퀴즈 내기→정답 공개 / 다음」

### 🔒 교재 문항 잠금
정적 호스팅에서는 화면 비밀번호가 보호가 되지 않는다(데이터 파일 주소를 직접 치면 그대로 받아진다).
그래서 **파일 자체를 AES-GCM으로 암호화**해 `bank.enc` 로만 올린다.

```bash
python build_lock.py
```

- 평문 `bank_book.js` 는 `.gitignore` 에 등록되어 있다. **절대 커밋하지 말 것.**
- 암호를 바꾸려면 `python build_lock.py --pw 새암호` 로 다시 빌드한다.
- 한 번 연 기기는 localStorage 에 기억해 다음부터 자동으로 열린다.

## 연출·수집

- 연출: `links/fx.js` (파티클·콤보·클리어 배너·별 등급·점수 카운트업). 소리는 기본 꺼짐.
- 진행 시각화: 홈 상단 **FAB LINE** — 배우기를 끝낸 만큼 웨이퍼가 스테이션을 지나갑니다.
  단원 수가 늘면 스테이션 크기가 자동으로 줄어 좁은 화면에서도 겹치지 않습니다.
- 결과 수집: `links/collector.js`. **`?rc=<선생님 Apps Script exec 주소>` 로 열었을 때만** 제출 버튼이 보입니다
  (빠른 점검 · 실전 모의고사에서만). 링크는 [결과수집 링크 생성기](https://hongyul67-cpu.github.io/links/link-builder.html)에서 뽑습니다.

## 자료가 들어오면 여기에 추가

`index.html` 안에 `[추가지점]` 주석 4곳이 있습니다.

1. **`[추가지점 1] CHAPTERS`** — 배우기 단원/쪽
   ```js
   {id:'c17', icon:'📘', title:'단원 제목', sub:'한 줄 설명', cards:[
     {h:'쪽 제목', lead:'부제', body:`HTML 본문`, tip:'헷갈리는 곳 짚기'},
   ]}
   ```
   `id`를 새로 주면 FAB LINE 스테이션도 자동으로 하나 늘어납니다.
   **배열 안의 위치가 곧 화면 순서**입니다(id 번호와 순서는 달라도 됩니다 — 실제로 c11~c16이 c3 앞에 놓여 있습니다).

2. **`[추가지점 2] SYMPTOMS / CALC`** — 진단 증상, 계산 문제 생성기
   `SYMPTOMS`는 **정답을 항상 `a:0`(첫 보기)로** 두면 됩니다. 화면에 뿌릴 때 자동으로 섞습니다.

3. **`[추가지점 3] BANK`** — 문제은행
   ```js
   {c:'c4', q:'문제', o:['보기1','보기2','보기3','보기4'], a:2, e:'해설'}
   ```
   `c`는 단원 id.

4. **`[추가지점 4] WEIGHT`** — 출제 비중(실전 60문항 중 몇 문항). **합계를 60으로** 맞춰 두면 됩니다.
   비중을 바꾸면 빠른 점검(20문항)의 배분도 같은 비율로 따라갑니다.
   한 단원의 WEIGHT보다 그 단원 문제 수가 적으면 있는 만큼만 나오고 모자란 자리는 다른 단원이 채웁니다.

## 출처 / 주의

- 자격 정보(명칭 변경·시험 구성·실기 과제)는 Q-Net과 공개 자료로 확인했습니다.
- **공식 출제기준**(2024.1.1~2028.12.31, 주요항목 9개)은 교재 앞부분에 실린 원문을 그대로 옮겨
  [출제기준.md](출제기준.md)에 정리했습니다.
- 단원 구성은 이 종목 표준 기출문제집(크라운출판사)의 **10 Part 목차**를 기준으로 맞췄습니다 —
  반도체 입문 / 사진 / 식각 / 확산 / CVD·PVD·RTS·ALD / 세정과 CMP / 조립 / 자동화 / 공유압 / 안전관리.
- 기출 170문항과 교재 60문항은 스캔 PDF에서 **직접 전사**했습니다.
  정답은 교재 정답표를 전 페이지 이미지로 판독해 확보했고, 본문은 한국어 OCR 결과를 원본과 대조해 정제했습니다.
- 그림은 원본 도해를 크롭해 수록했습니다(문제 그림 10장 + 수업 슬라이드 그림 10장).
- ⚠️ **교재 문제편 701문항 중 60문항까지 반영했습니다.** 나머지는 순차 작업 중이며,
  특히 자동화·공유압(215문항)이 가장 큰 몫입니다.

실기(반도체장비조립작업 1시간 + 반도체장비제어작업 2시간 30분)는 이 도구에 없습니다. 별도 도구로 분리 예정.
