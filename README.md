# 반도체설비보전 마스터

반도체설비보전기능사(구 **반도체장비유지보수기능사**, 2024년 명칭 변경) **필기 개념** 학습도구.
단일 HTML 하나(`index.html`)로 끝나고, 더블클릭으로도 열립니다.

## 구성

| 단계 | 내용 |
|---|---|
| 📖 배우기 | 10단원 45쪽. **정답이 다 적혀 있는** 설명 카드를 넘기기만 하면 됩니다 |
| 🎮 게임 | ① 8대 공정 라인 세우기 ② 설비 이상 진단실(18증상) ③ 설비 계산소(생성기 12종, 매번 숫자가 바뀜) |
| 🎯 테스트 | 문제은행 66문항에서 **10단원 × 2문항 = 20문항** 출제, 오답노트 + 결과 제출 |

단원: ① 반도체와 팹 ② 8대 공정 ③ 장비 요소기술(진공·가스·온도) ④ 설비보전 이론 ⑤ 자동화·공유압
⑥ 안전관리 ⑦ 기계요소와 정비 기초 ⑧ 전기·전자 기초 ⑨ 측정·진단·고장분석 ⑩ 팹 유틸리티와 장비 반입

계산소가 내는 문제: MTBF · MTTR · 가용도 · 시간가동률 · OEE · 고장률 λ · 신뢰도(직렬/병렬) ·
공압 실린더 출력(F=P×A) · 옴의 법칙 · 병렬 합성저항 · 베어링 호칭번호 안지름

## 연출·수집

- 연출: `links/fx.js` (파티클·콤보·클리어 배너·별 등급·점수 카운트업). 소리는 기본 꺼짐.
- 진행 시각화: 홈 상단 **FAB LINE** — 배우기를 끝낸 만큼 웨이퍼가 스테이션을 지나갑니다.
- 결과 수집: `links/collector.js`. **`?rc=<선생님 Apps Script exec 주소>` 로 열었을 때만** 제출 버튼이 보입니다(종합 테스트에서만).
  링크는 [결과수집 링크 생성기](https://hongyul67-cpu.github.io/links/link-builder.html)에서 뽑습니다.

## 자료가 들어오면 여기에 추가

`index.html` 안에 `[추가지점]` 주석 3곳이 있습니다.

1. **`[추가지점 1] CHAPTERS`** — 배우기 단원/쪽 추가
   ```js
   {id:'c7', icon:'📘', title:'단원 제목', sub:'한 줄 설명', cards:[
     {h:'쪽 제목', lead:'부제', body:`HTML 본문`, tip:'헷갈리는 곳 짚기'},
   ]}
   ```
   `id`를 새로 주면 홈의 FAB LINE 스테이션도 자동으로 하나 늘어납니다.

2. **`[추가지점 2] SYMPTOMS / CALC`** — 진단 증상, 계산 문제 생성기 추가
   `SYMPTOMS`는 **정답을 항상 `a:0`(첫 보기)로** 두면 됩니다. 화면에 뿌릴 때 자동으로 섞습니다.

3. **`[추가지점 3] BANK`** — 테스트 문제은행
   ```js
   {c:'c4', q:'문제', o:['보기1','보기2','보기3','보기4'], a:2, e:'해설'}
   ```
   `c`는 단원 id. **단원별로 2문항씩** 먼저 뽑고 나머지를 채워 20문항을 만듭니다.
   단원을 더 늘리면 `startTest()`의 `slice(0,2)` 숫자를 조정해야 20문항이 유지됩니다.

## 출처 / 주의

공개된 출제기준·직무모형(반도체공정개론 / 신규설비 / 예방·사후·개량보전 / 자동화기초·공유압 / 안전관리)을 바탕으로
**개념 학습용**으로 작성했습니다. 기출문제집·교재의 실제 문항은 아직 들어 있지 않습니다 — 자료 확보 후 `BANK`에 추가.

실기(반도체장비조립작업 1시간 + 반도체장비제어작업 2시간 30분)는 이 도구에 없습니다. 별도 도구로 분리 예정.
